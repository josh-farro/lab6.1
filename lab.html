Web Application Security Lab

📋 Lab Overview

This lab demonstrates common web application vulnerabilities in a controlled environment. Your task is to identify, test, and fix these vulnerabilities.

Learning Objectives:

  • Identify XSS vulnerabilities (Reflected, Stored, DOM-based)
  • Understand SQL injection concepts through simulation
  • Recognize business logic flaws
  • Implement security fixes
  • Create vulnerability reports

🔍 Phase 1: Reconnaissance & Mapping

Objective: Map all input sources and output sinks in the application.

Tasks:

  1. Explore all pages of the application
  2. Identify all user input fields
  3. Map where inputs are stored (localStorage, in-memory DB)
  4. Identify where inputs are rendered/output (DOM sinks)
  5. Document data flow from source to sink

Deliverable: Source-to-Sink Map

Create a table documenting:

  • Input source (URL, form field, etc.)
  • Storage location
  • Output sink
  • Vulnerability type

🔧 Phase 3: Fix Implementation

XSS Fixes:

// VULNERABLE element.innerHTML = userInput; // SAFE element.textContent = userInput; // OR element.innerHTML = encodeHTML(userInput);

SQL Injection Fixes:

// VULNERABLE const query = `SELECT * FROM orders WHERE id = '${userInput}'`; // SAFE const query = db.prepare('SELECT * FROM orders WHERE id = ?'); query.bind([userInput]);
